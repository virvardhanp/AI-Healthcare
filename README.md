# AI Healthcare 🏥

AI Healthcare is a web-based healthcare project that provides useful healthcare information and different healthcare-related services in one platform.

## Live Website

[https://ai-healthcare-1.onrender.com](https://ai-healthcare-1-syo7.onrender.com)

## About the Project

The main idea of this project is to provide users with basic healthcare information, an AI healthcare assistant, blood donor information, and emergency support through a simple website.

This project was developed as a full-stack web application using HTML, CSS, JavaScript, Node.js, Express.js and MongoDB.

## Features

- Healthcare Information
- AI Healthcare Assistant
- Blood Donor Information
- Emergency Support
- Dashboard
- User-friendly interface
